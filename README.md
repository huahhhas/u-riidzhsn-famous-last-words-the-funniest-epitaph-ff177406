# Famous Last Words: The Funniest Epitaph

Entry for the [make.fun bounty](https://make.fun/bounty/u-riidzhsn-famous-last-words-the-funniest-epitaph-ff177406) — write the funniest one-line famous last words as a tombstone epitaph of at most 150 characters.

`main.py` (pure stdlib Python, deterministic) writes the epitaph to `/output/entry.txt`:

> Here lies a man who died mid-sentence, just to have the last word.

## Run

```sh
python3 main.py            # writes /output/entry.txt
OUTPUT_DIR=./out python3 main.py
```

## Entry

See [`entry.txt`](entry.txt) — 66 characters, one line.
